# 日本語

# Vosk を使用した音声認識について
- [こちら](https://alphacephei.com/vosk/models/vosk-model-ja-0.22.zip) から日本語モデルをダウンロードしてください
- 解凍後、フォルダ名が `"vosk-model-ja-0.22"` になっていることを確認してください
- フォルダごと `"Assets/StreamingAssets/"` の中に配置してください

# MediaPipe を使用したハンドジェスチャー認識について
- [こちら](https://github.com/homuler/MediaPipeUnityPlugin/releases/download/v0.16.3/com.github.homuler.mediapipe-0.16.3.tgz) から `.tgz` ファイルをダウンロードしてください
- 解凍せず、そのまま使用してください
- ファイルを `"Assets/UnUploadables/"` の中に配置してください
- その後、Unity Editor を開いてください

# ビルド後のゲーム実行について
- このゲームを実行するには、PC に `"vc_redist.x64.exe"` のインストールが必要です
- [こちら](https://aka.ms/vc14/vc_redist.x64.exe) からダウンロードしてください
- 実行してインストール後、PC を再起動してからゲームを起動してください

# English

# To use Vosk for Speech Detection
- Download the Japanese language model from [this link](https://alphacephei.com/vosk/models/vosk-model-ja-0.22.zip)
- Extract it and make sure the folder name is `"vosk-model-ja-0.22"`
- Place the whole folder in `"Assets/StreamingAssets/"`

# To use Mediapipe for Hand Gesture Detection
- Download the `.tgz` file from [this link](https://github.com/homuler/MediaPipeUnityPlugin/releases/download/v0.16.3/com.github.homuler.mediapipe-0.16.3.tgz)
- Do not extract it
- Place the file in `"Assets/UnUploadables/"`
- Then open the Unity Editor

# To run the built game
- This game requires `"vc_redist.x64.exe"` to be installed on the PC
- Download it from [here](https://aka.ms/vc14/vc_redist.x64.exe)
- Run the installer and restart the PC before launching the game
